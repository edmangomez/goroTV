# Skill: UI Design System (goroTV)

Definición visual y tokens de interfaz para goroTV.

## Paleta de Colores
- **Fondo Base (Dark TV)**: `#0B0F19` (negro azulado profundo para reducir fatiga visual en pantallas OLED/LED).
- **Fondo Superficie (Cards/Modales)**: `#131B2E`
- **Fondo Hover/Foco**: `#1E293B`
- **Acento Primario**: `#3B82F6` (Azul eléctrico vibrante para foco y botones activos).
- **Acento Secundario**: `#6366F1` (Índigo).
- **Éxito (Suscripción Activa)**: `#10B981` (Verde esmeralda).
- **Alerta (Por Vencer)**: `#F59E0B` (Ámbar).
- **Peligro (Vencido / Error)**: `#EF4444` (Rojo carmesí).
- **Texto Primario**: `#F8FAFC` (Blanco casi puro).
- **Texto Secundario**: `#94A3B8` (Gris frío).

## Tokens de Enfoque TV (D-Pad)
- `outline`: `3px solid #3B82F6`
- `outline-offset`: `2px`
- `transform`: `scale(1.04)` con `transition: transform 150ms ease-out`
- `box-shadow`: `0 0 20px rgba(59, 130, 246, 0.4)`
