# Skill: Senior Prompt Engineer (goroTV)

Especializada en estructuración de contexto, instrucciones sin ambigüedades y verificación estricta.

## Principios
1. **Contexto Completo**: Especificar siempre el target de ejecución (Smart TV browser, Chromium webOS, Android TV Capacitor).
2. **Definición de Salidas**: Solicitar tipado TypeScript estricto, interfaces explícitas y manejo de casos límite (streams nulos, respuestas de red lentas, errores 403).
3. **Validación Iterativa**: Probar cada módulo antes de pasar al siguiente.
